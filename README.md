# TOEFL 교정 코치

TPO 2·3·4의 실제 오답 63개에서 출발하는 개인 오답 교정 프로그램.
설계 근거와 전체 명세는 [DESIGN.md](DESIGN.md).

## 열기

- **웹 (어느 기기·브라우저든)**: https://taebin.link/toefl-coach/ — 공개 GitHub Pages. `main`에 푸시하면 1분 안에 반영됩니다.
- **claude.ai**: https://claude.ai/artifact/Fe41uCcXgejYEBaXZwBzsm — claude.ai 계정 저장소로 자동 동기화 (위 웹 버전과 기록은 별개).

### 기기 동기화 (웹 버전, jsonbin)
1. 처음 한 기기: 설정 → 기기 동기화 → jsonbin.io의 X-Master-Key 입력 → "저장소 만들고 연결". 동기화 코드(`TCSYNC1.…`)가 나옵니다.
2. 다른 기기: 설정 → 기기 동기화 → 동기화 코드를 한 번 붙여넣기. 그 기기의 기존 기록은 공유 기록으로 대체됩니다.
3. 이후 자동: 학습 중 1분마다, 페이지를 떠날 때 저장 / 다시 열거나 탭으로 돌아올 때 불러오기. 두 기기에서 동시에 풀면 나중 저장이 이깁니다.
- 동기화 코드에는 jsonbin 키가 들어 있으니 공유하지 마세요. 키는 저장소(코드)에 들어가지 않고 각 기기 브라우저에만 저장됩니다.
- jsonbin 무료 한도: 저장 단위당 100KB(압축 후). 넘으면 상단 표시에 오류가 뜹니다.

## 실행 (로컬)

맥에서 `start.command`를 더블클릭하면 로컬 서버가 켜지고 브라우저가 열립니다 (http://localhost:8765).
터미널에서 실행하려면:

```bash
python3 -m http.server 8765
```

- 학습 기록은 **브라우저에 자동 저장**됩니다 (주소별로 따로 저장되므로 항상 같은 주소로 여세요).
- 휴대폰: 같은 와이파이에서 `start.command` 창에 표시되는 주소로 접속. 기기마다 기록이 따로이므로 설정 → 내보내기/가져오기로 옮깁니다.
- 매주 한 번 설정 → **내보내기**로 JSON 백업을 권장합니다.

## 하루 흐름

오늘 화면 → 시작 → (유지 확인) → 집중 능력 2개: 원본 오답 재판단 → 판단 순서 → 연습 → 새 문제 → 섞어 풀기 → 종료.
중간에 나가도 그 단계부터 이어집니다.

## 새 모의고사 오답 추가

1. 틀린 문제 화면을 캡처해 `tpo오답/<날짜>_<회차>/`에 넣습니다 (예: `tpo오답/2026-10-20_TPO5/`).
   리스닝은 **스크립트 화면도 함께** 캡처하면 음원을 다시 만들 수 있어 분석이 정확해집니다. 세트의 문항 번호 색(정답/오답)이 보이게 찍으면 성적도 기록됩니다.
2. Claude에게 "TPO5 오답 분석해서 추가해줘"라고 요청합니다. 절차는 [CLAUDE.md](CLAUDE.md)에 있어 매번 같은 방식으로 처리됩니다:
   전사 → 8개 능력으로 분류 → 오답 리포트 → `content/tests/TPO5.json` → QA → (필요하면 새 문제) → 빌드.
3. 앱을 새로고침하면:
   - **TPO 탭**에서 회차별 리포트와 능력별 오답 수 변화를 봅니다.
   - 새 오답이 원본 확인 단계로 오늘 훈련에 들어갑니다.
   - "개선됨"이던 능력에서 실전 오답이 나오면 자동으로 **재발**이 되어 다시 집중 대상이 됩니다.

## 훈련 중 기록되는 것 (이전 사이트의 장점 반영)

- **내 규칙**: 원본 오답을 확인할 때 "다음에 이 유형이 나오면 나는…"을 내 말로 적습니다. 판단 순서 카드와 오답 피드백에 다시 나옵니다.
- **재발 판정**: 새 문제를 틀리면 "같은 원인 / 규칙은 알았는데 적용 못함 / 다른 원인 / 모르겠음"을 고릅니다 → 변화 탭에 누적.
- **리스닝 막힌 지점**: 리스닝을 틀리면 "안 들렸다 / 잊었다 / 선택지에서 헷갈렸다 / 뜻을 몰랐다"를 고르고, 스크립트를 보기 전에 **근거 구간만 다시 듣기** → "이제 들린다 / 여전히 안 들린다". 소리 인식 문제인지 기억 문제인지가 변화 탭에 쌓입니다.

## 콘텐츠 추가 / 수정

```
content/originals.json     실제 TPO 오답 (UNKNOWN은 null)
content/skills.json        8개 능력과 판단 순서
content/items_*.json       새 문제 (Guided / Transfer) + 음원 스크립트
```

수정 후:

```bash
python3 tools/build.py
```

QA 검사(정답 1개, 근거 문장이 지문/스크립트에 실제로 있는지, 원본 정답 재사용 금지 등) → macOS `say`로 음원 생성 → `app/content.js` 생성.
QA를 통과하지 못한 문제는 빌드가 실패하므로 앱에 들어가지 않습니다.

다음 TPO를 풀면 오답을 같은 형식으로 `originals.json`에 추가하세요 (`tests`에도 성적 추가). 우선순위가 자동으로 다시 계산됩니다.
