# 시험 화면 규칙 (소站 TPO独家 기준)

앱의 실전 화면은 이 표의 규칙만 따른다. 문항 원문은 여기 없다 (공개 문서).
출처 구분:
- **소站 데이터** — 리포트 페이지가 내려 준 문항 데이터 필드에서 직접 확인 (`private/zhan/raw/*.json`, 2026-11-01 수집).
- **사용자 명세** — `OVERHAUL.md` 원칙 5에 사용자가 적은 조건. 소站 시험 화면에서 Claude가 직접 보지는 못했다.
- **미확인** — 확인하지 못함. 앱은 기존 동작을 유지한다.

소站 시험 화면은 새 응시를 시작해야만 볼 수 있어 (OVERHAUL.md 원칙 7: 응시 시작 금지) 직접 확인하지 않았다. 리포트 화면과 사용자의 기존 캡처(`../tpo오답/`)는 모두 리포트(채점 후) 화면이다.

## 구성 (소站 데이터)

| 영역 | 모듈 1 | 모듈 2 |
|---|---|---|
| 리딩 | C-Test 10칸 · 일상 지문 2세트(2+3문항) · 학술 지문 5문항 | C-Test 10칸 · 일상 지문 2세트 (+ 회차·경로에 따라 학술 지문) |
| 리스닝 | 응답 고르기 12 · 대화 3세트(각 2) · 공지 4세트(각 2) · 강의 1세트(4) | 응답 고르기 3 · 대화 2세트 · 강의 2세트 |
| 말하기 | Listen & Repeat 7문장 · Interview 4문항 | — |
| 쓰기 | Build a Sentence 10 · Email 1 · Academic Discussion 1 | — |

모듈 2는 적응형이라 회차마다 문항 수가 다르다 (예: 독점 TPO 15 리딩 모듈 2 = 15문항, 다른 회차 15~28).

| 규칙 | 값 | 출처 |

| Build a Sentence 시간 | 미확인 (문항 필드에 시간 없음) | 미확인 |
| 리딩 모듈 시간 제한 | 미확인 | 미확인 |

| 문항별 시간 제한 (리딩·리스닝) | 미확인 | 미확인 |

## 화면 조건

| 조건 | 앱 동작 | 출처 |
|---|---|---|
| 음성이 끝까지 재생된 뒤 문제가 보인다 | 실전 화면(리스닝·말하기)에서 적용 | 사용자 명세 |
| 남은 재생 시간·진행바가 보이지 않는다 | 실전 화면에서 적용 | 사용자 명세 |
| 다시 듣기 불가 | 실전 화면에서 적용 (채점 후 복습 화면에서는 다시 듣기 가능) | 사용자 명세 |
| Listen & Reply 질문 문장은 글로 보이지 않는다 (음성만) | 적용 — 소站 데이터의 문항 문장이 곧 들려주는 말이라 실전에서는 숨김 | 소站 데이터(문항=음성 문장) + 사용자 명세(다시 듣기 불가) |
| 이전 문제로 돌아가기 | 미확인 → 기존 동작 유지 (리딩 세트 안에서는 이동 가능, 리스닝은 앞으로만) | 미확인 |
| 섹션 남은 시간 표시 | 미확인 → 표시하지 않음 (기존 동작) | 미확인 |
| 쓰기 남은 시간 표시 | 미확인 → 표시 (기존 동작) | 미확인 |

## 모의 모듈용 보류 회차

- **독점 TPO 2** (paperId 240) → 11/7 모의 모듈 · **독점 TPO 3** (paperId 241) → 11/12 모의 모듈.
- 이유: 리스닝까지 전부 받을 수 있는 회차(2·3·4·5·6·7·8·15) 중 가장 오래전(10/2·10/8)에 푼 두 회차라 기억이 가장 흐리다. 리스닝 없는 회차(1·9~14)는 모의 모듈(R+L)로 쓸 수 없다.
- 이 두 회차의 문항은 일상 계획(새 문제·쌍둥이·섞어 풀기)에 나오지 않는다. 내 기존 원본 오답(TPO2·3 기록)은 그대로 다시 풀기 대상이다.
