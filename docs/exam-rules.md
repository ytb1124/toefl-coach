앱의 실전 화면은 이 표의 규칙만 따른다. 문항 원문은 여기 없다 (공개 문서).
출처 구분:
- **소站 화면** — 2026-11-01 사용자 요청으로 독점 TPO 14(paperId 257, 보류 회차 아님)의 리딩·리스닝·쓰기 새 응시를 시작해 Claude가 직접 본 것. 답 제출·채점 없이 중간에 나왔다.
- **소站 데이터** — 리포트 페이지가 내려 준 문항 데이터 필드에서 확인 (`private/zhan/raw/*.json`).
- **미확인** — 확인하지 못함. 앱은 기존 동작을 유지한다.

말하기는 시작 후 '마이크 확인' 화면에서 멈췄다 (마이크 권한 필요 → 원칙 7에 따라 권한을 주지 않음). 말하기 시간 규칙은 소站 데이터로만 확인했다.

| 조건 | 소站에서 본 것 | 출처 |

| 다시 듣기 | 리스닝: 다시 듣기 버튼 없음 (볼륨 조절만) | 소站 화면 |

| 말하기 화면 | 미확인 (마이크 확인에서 멈춤) → 기존 동작 + 데이터의 응답 시간 | 미확인 |

### 사용자 명세(OVERHAUL.md 원칙 5)와 다른 점
- "음성이 끝까지 재생된 뒤 문제가 보인다" — 대화·공지·강의는 맞다. **응답 고르기는 보기가 재생 중에도 보인다** (질문 문장만 안 보임). 앱은 소站 화면대로 한다.
- "남은 재생 시간이 보이지 않는다" — 맞다 (음성 진행바·남은 재생 시간 없음). 단, 문항·모듈 **남은 답 시간**은 보인다 (숨기기 가능).

## 모의 모듈용 보류 회차

- **독점 TPO 2** (paperId 240) → 11/7 모의 모듈 · **독점 TPO 3** (paperId 241) → 11/12 모의 모듈.
